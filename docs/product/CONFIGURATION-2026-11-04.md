# 用户配置与首页模块化 · 2026-11-04

用户新需求优先于原路线顺序：.env 初始化，前台增删改，多账号，勾选/拖拽首页，简单易用。

已实施：
- 环境变量单次导入（含编号槽位），导入标记持久化，前台修改不被覆盖、删除不复活；不再隐式导入本机百炼 CLI 为新账号。
- 账号管理支持同平台多个 API/会员手工记录，留空 Key 保留原秘密，清空可选字段，按平台给出接入说明；平台切换不隐式复用旧平台秘密。
- 每账号独立卡片，百炼、智谱 Code Plan、xAI 管理查询独立；本机 Codex/Kimi 当前会话保留，其他会员账号手工记录。
- 首页持久化模块选择/顺序，HTML 拖拽手柄与上下按钮；已保存布局不自动加入新账号。配额页独立保留汇总卡片、详情轮播、缓存与单卡刷新。
- 个人百炼账号设为当前主账号；公司账号按最新要求设为 `trial_only`，从首页模块、配额及「其他账号」列表排除，保留模型体验调用和账号管理编辑。首页点击「编辑首页」选择模块，点击「编辑账号」修改账号。
- 分享仍独立裁剪，不因首页选择而公开更多个人数据。

验证：27 项 unittest 通过（含个人主账号默认展示、仅模型体验账号隐藏与凭证保留回归）；新增覆盖环境变量重复导入、修改/删除重启语义、掩码 Key 保留、多个会员记录、0% 与 null、布局排序/全隐藏/删除账号、百炼换 Key 清除旧授权、智谱多账号缓存隔离，以及 API 新增→编辑→布局→读取→删除流程。前端 JS 语法检查通过，运行中 API 与静态资源已验证，服务已重启。

浏览器自动化连接超时，真实浏览器拖拽、手机排版、键盘焦点流程尚未视觉验收；不能据此将 UX-001 或 ONB-001 整项标为完成。下一轮优先补浏览器验收，不迁移或删除真实账号数据。

## 首页缓存与卡片展示补充

首页先用 `cache_only=true` 读取与配额页相同的源快照，不等待 CLI 锁或发起外网请求；有缓存立即展示，缺失/超过全局分钟设置时再更新。手动刷新使用 `force=true`，失败保留已有数据。智谱和 xAI 沿用各账号独立指纹缓存。

卡片宽屏最多四列，随屏幕缩为三/二/一列；强化标题、额度、重置时间和更新时间，默认环境变量后缀从展示标题中省略。29 项测试通过，覆盖过期缓存只读、无缓存首次获取、缓存复用和手动刷新。真实首页已检查四列与缓存标签。

## 统一卡片与秒级倒计时

卡片固定同宽同高（640px），主额度大环图，其他额度紧凑小环图，更多窗口可在卡片内滚动。平台作主标题，账号或套餐作副标题；保留缓存来源及更新时间。倒计时仅在前端每秒计算，不发网络请求；1 小时内橙色、15 分钟内红色轻微呼吸；重置到期显示等待更新，不虚构额度恢复。支持减少动态效果的系统偏好。切换页面清理计时器。前端语法检查通过，真实浏览器已确认秒数变化、红色紧迫提示和等尺寸环图卡片。

## 五棵松的大屏首页

首页标题改为「五棵松的工作台」，醒目标语为「让每一份 AI 能量，都用在创造上。」。首页最大宽度提升为 1920px、最多四列；宽屏放大环图和倒计时，卡片保持等尺寸。首页及各卡片的操作统一收进原生 details/summary 三点菜单，支持键盘、Esc、点击外部关闭。菜单提供编辑、账号管理、刷新、排序及官网入口；拖动手柄仅在编辑模式显示。首页菜单的大屏展示可隐藏导航，Esc 或同一菜单退出，不改变缓存和账号设置。

脚本语法及差异检查通过；本轮浏览器连接超时，新增大屏布局和菜单尚未完成视觉验收。
